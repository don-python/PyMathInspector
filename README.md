# 🚀 PyMathInspector

### Analiza, comprende y visualiza funciones matemáticas con Python.

PyMathInspector es una herramienta educativa desarrollada en Python que permite identificar y analizar expresiones matemáticas de manera sencilla e interactiva. Su objetivo es facilitar la comprensión de las funciones mediante información matemática y representaciones gráficas.

---

## ✨ Funcionalidades

- 🔎 **Identificación automática:** reconoce funciones polinómicas según su grado.
- 📐 **Análisis matemático:** calcula raíces e intersecciones con el eje Y.
- 📊 **Representación gráfica:** genera gráficos de las funciones ingresadas.
- 📍 **Cálculo del vértice:** obtiene el vértice y la concavidad de funciones cuadráticas.
- ⌨️ **Ingreso simplificado:** permite escribir expresiones como `2x^2 + 3x + 1`, sin necesidad de utilizar `*` para multiplicar.

## 🛠️ Tecnologías

| Tecnología | Utilidad |
|---|---|
| Python | Lenguaje de programación |
| SymPy | Análisis matemático |
| NumPy | Cálculos numéricos |
| Matplotlib | Generación de gráficos |
| Tkinter | Interfaz gráfica |

## ⚙️ Instalación y ejecución

**1. Clonar el repositorio**

```bash
git clone URL_DEL_REPOSITORIO
```

**2. Instalar las dependencias**

```bash
pip install sympy numpy matplotlib tkinter
```

**3. Ejecutar el programa**

```bash
python pymathinspector.py
```

## 💡 Ejemplos de uso

Puedes ingresar expresiones como las siguientes:

```python
2x + 3
x^2 + 2x - 3
2x^3 + 2x^2 + 2x + 1
```

PyMathInspector analizará la expresión, identificará el tipo de función y mostrará sus características junto con su gráfico.
